# User Management API
 
ASP.NET Core Web API developed for TechHive Solutions.
 
## Features
 
- CRUD operations
- Logging middleware
- Authentication middleware
- Global exception handling
- Swagger documentation
 
## Technologies
 
- ASP.NET Core 8
- C#
- Swagger/OpenAPI
- GitHub
 
## Endpoints
 
GET /api/users
 
GET /api/users/{id}
 
POST /api/users
 
PUT /api/users/{id}
 
DELETE /api/users/{id}
